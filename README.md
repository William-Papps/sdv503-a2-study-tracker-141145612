# sdv503-a2-study-tracker-141145612

This is a simple terminal / command-line Study Tracker Application.
This app let's the user record study sessions, view saved sessions, and calculate the total amount of minutes they've studied.

List of features
- Add a "study session" with a topic and an amount of minutes studied
- Rejects an empty study topics
- Rejets any invalid minute input such as, letters, decimals, zero and negative numbers
- Can list all of the saved study sessions
- Show's the total number of minutes studied
- Allow's the user to at any point exit the application
  
# How to use the application
Make sure you have node.js installed on your device
type in git bash terminal while in the application folder directory
node app.js

Use the inputs 
1 - Add a new study topic
2 - Display Study's
3 - Total study time
4 - exit
